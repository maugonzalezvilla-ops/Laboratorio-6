El mundo de las IT

La tecnología detrás de lo cotidiano.

Computadoras, redes y datos: una mirada sencilla a lo que mantiene conectado nuestro mundo.

01

¿Qué significa IT?

IT viene de Information Technology, que en español significa tecnologías de la información o TI. Este campo reúne herramientas para almacenar, procesar y compartir información. Incluye equipos físicos, programas y redes. Cuando una escuela administra calificaciones o una empresa organiza sus archivos digitales, está utilizando tecnologías de la información.

02

Todo está conectado

Una red permite que diferentes dispositivos intercambien información. Por ejemplo, una computadora puede enviar un archivo a un servidor para que otras personas autorizadas lo consulten. Internet conecta redes a gran escala, mientras que una red local puede funcionar dentro de una casa, una escuela o una oficina.

03

Crear soluciones, cuidar datos

Las IT también incluyen el desarrollo de software, el soporte técnico y la protección de la información. Una aplicación útil debe resolver una necesidad y manejar los datos con cuidado. En esta actividad practico una pequeña parte de ese mundo: organizar contenido con HTML y darle presentación mediante CSS y Bootstrap.

Para llevarte una idea: Ejemplo cercano: al entrar a una plataforma escolar participan tu dispositivo, una red, un servidor y un programa.

En un caso típico, el navegador localiza el servidor mediante DNS y solicita los archivos de la página. Después interpreta el HTML, aplica el CSS y ejecuta el JavaScript necesario. En este proyecto los archivos están en tu computadora, por eso puedes abrirlo sin conexión.
